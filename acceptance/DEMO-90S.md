# FlowBack 黑客松 90 秒演示脚本（R2 真实 AI 版）

> 预录版：`demo/FlowBack-Product-Demo.mp4`（52 秒，真实截图调用）。  
> 预检：打开 <http://127.0.0.1:4317>，右上角必须是 **“AI 已连接”**。  
> 如果显示“示例模式”，只能说“本地规则示例”，不能说“真实 AI”。

## 0:00–0:08 问题

“群聊里决定了很多事，但没人记得谁在什么时候交什么。FlowBack 把聊天和截图，变成可审核、可执行、可追溯的任务，并在开工前指出责任空缺、时间冲突和未确认决策。”

## 0:08–0:20 真实 AI 入口

- 首页指出：**上传截图**按钮、聊天文字、示例入口；右上角“AI 已连接”证明服务端已配置 DeepSeek。
- 展示真实 AI 项目入口：`R2 发布演示`（<http://127.0.0.1:4317/dashboard/prj_5d2229e959ee456eae1a>）；或点“上传截图”，选择 `acceptance/images/07-chat-conflict.png`。
- 说：“截图会走 DeepSeek Vision 真实推理，不是本地模拟。”

## 0:20–0:38 审核台：原文 ↔ 任务

- 左侧截图/原文高亮；右侧任务卡逐条对应。
- 指出：`提交主视觉海报最终稿 / 小王 / 周四`、`提交海报初稿 / 小王 / 周五`、`联系场地 / 无人负责`。
- 指出风险：**时间冲突**、**无人负责**、**截止待定**。
- 把场地负责人改为“陈默”，截止改为“11月2日前”；展示“草稿已自动保存”。
- 强调：“AI 只是候选，确认前不写库；‘收到’不是完成。”

## 0:38–0:52 确认 → 看板

- 点“确认建立任务”。
- 看板：3 个任务、完成率、进行中、风险。
- 点最终稿 → 改为“进行中”；卡片显示完成证据/原文引用。
- 刷新页面，状态仍在；事件和原文都保留。

## 0:52–1:08 风险中心

- 打开“风险中心”：时间冲突/责任空缺/截止待定筛选。
- 打开 due_conflict，展示原文与“查看来源审核存档”。
- 点“标记解决”，写处理说明；再展示“重新打开”的能力。
- 强调：风险可追溯、可修改、可解除；解决后仍保留记录。

## 1:08–1:22 收尾

- 打开来源审核存档，展示“真实 AI · deepseek-flash”标签。
- 打开 `acceptance/REPORT.md`：7/7 PASS、任务 F1 100%、风险召回 100%、引用 100%、7 次真实调用、17,304 tokens。
- 结束句：“FlowBack 不替你开会，但让会后的每一句话都有着落。”

## 时间不够的最短路径

1. 首页“加载示例” → 运行真实 AI 解析（约 3 秒）。
2. 审核台指出时间冲突 + 无人负责。
3. 确认 → 看板改状态。
4. 风险中心解决一条。
5. 刷新证明持久化。

## 失败 Plan B

- **无 Key**：使用示例模式，明确说“本地规则，不是 AI”；不展示准确率。
- **API 失败**：首页/审核台有明确错误与重试；不掩盖 401/429/余额问题。
- **图片识别偏差**：指出“需人工确认”标记，现场以审核台修正；不要声称 100% OCR。

## 不要说的话

- 不要指着“示例模式”结果说“这是真实 AI”。
- 不要说“准确率 100% 是通用能力”；只能说“本轮 7 组夹具 7/7，样本有限”。
- 不要展示或口述 API Key。
